# cat-fish

Aquário interativo feito com HTML, CSS e Canvas 2D.

## Executar

Abra `index.html` em um navegador. Não há dependências de instalação nem processo de build. A fonte Fredoka é carregada do Google Fonts; se estiver offline, o navegador usa a fonte alternativa.

## Estrutura

- `index.html`: estrutura e carregamento dos recursos.
- `css/style.css`: estilos, tema e layout responsivo.
- `js/script.js`: desenho do aquário, animações, áudio e interações.
